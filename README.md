# Movie React 🎬

A React movie discovery application built to practice API consumption, component architecture, search experiences, and responsive frontend development.

## About

The project provides a movie-focused interface where users can explore and discover titles through data retrieved from a movie API.

## Features

- Movie discovery and browsing
- Search-oriented UI
- External API integration
- Reusable React components
- Responsive design

## Tech Stack

- React
- JavaScript
- CSS3
- REST API

## Topics

`react` `javascript` `movie-app` `api` `rest-api` `frontend` `responsive-design`

## Getting Started

```bash
git clone https://github.com/ElmehdiElkabia/movie-react.git
cd movie-react
npm install
npm start
```
